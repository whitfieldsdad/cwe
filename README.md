# Common Weakness Enumeration (CWE) parser

This is a lossy, non-exhaustive parser for the MITRE Common Weakness Enumeration (CWE) dataset - it makes no attempt to parse the entire dataset <sub>1</sub>.

<sub>1. Parsing the entire dataset would be nice, though.</sub>

## Features

- Download the latest version of the MITRE CWE weakness catalog
- Extract weaknesses, categories, and views
